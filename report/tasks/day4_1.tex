\begin{maintask}{4-1}
  \subsection*{課題内容}
  UDPサーバ\texttt{udp\_server.py}とUDPクライアント\texttt{udp\_client.py}を実行し，クライアントから送信したデータをサーバが受信することを確認する．

  \subsection*{実験方法}
  \begin{enumerate}
    \item サンプルをホームディレクトリにコピーし，サーバを起動する．
      \begin{minted}{zsh}
        cd
        cp -r /shares/socket .
        cd socket
        ./udp_server.py
      \end{minted}
    \item 別の演習環境からクライアントを起動する．
      \begin{minted}{zsh}
        cd socket
        ./udp_client.py
      \end{minted}
    \item サーバ側とクライアント側の出力を確認し，サーバをCtrl-Cで停止する．
  \end{enumerate}

  \subsection*{結果}
